# Proposal

## Why

第3课交付了登录、班级隔离与材料入库，但"知识库"目前只是文本及关联记录：既不能按语义检索，也无法回溯到出处。教师和学生需要以一句自然语言在本班材料中定位相关片段，并在回答中标注来源；当资料中不存在依据时，必须明确返回未找到，不得编造出处。本次为第4课形成可评审、可验证的检索变更合同。

## What Changes

- 材料入库后追加切分与向量嵌入：正文按切分策略拆分为切片写入 `knowledge_chunks`，向量写入 Qdrant；向量主键与 `knowledge_chunks.id` 相同。嵌入失败不回滚材料记录，对应切片标记为 failed，不写入不完整的向量数据。
- 支持三种切分策略：`auto`（默认，最大约 800 字、重叠 80 字，优先在空行/换行/句号处断开）、`custom`（最大 100–2000 字、重叠 0%–50%，可移除 URL/邮箱或折叠空白）、`hierarchy`（按 `#`/`##`/`###` 分章，标题保留在章内）。未指定时等同 `auto`，种子材料亦采用 `auto`。预处理不改写 `body_text`，偏移相对预处理后文本；切换策略 MUST 显式重建索引。
- 新增班级范围内的检索接口，支持三种模式（默认 `hybrid`）：`keyword` 仅查询 MySQL 全文索引（`FULLTEXT ... WITH PARSER ngram`，token 长度 2），不调用嵌入服务；`vector` 将问句嵌入后在 Qdrant 按 `class_id` 过滤，余弦相似度低于 0.35 的候选丢弃，再按向量主键回表取正文；`hybrid` 同时执行两路，各自过滤后按名次执行 RRF（`k = 60`）融合。
- 每条命中 MUST 可回溯至原文：至少给出材料标题、切片序号、字符区间与一段摘录，并支持打开对应材料；摘录取自 MySQL 的 `chunk_text`，而非向量库。
- 新增问答接口 `POST /api/ask`：由检索模块以混合模式取回本班前 4 条切片；存在命中时把材料标题、切片序号与切片正文连同提问交给对话网关，回答以 `[1]`、`[2]` 指回出处，`citations` 顺序与标注一致；无命中时直接返回「资料中未找到相关内容」且 `citations` 为空，不调用对话网关。客户端注入的 `system` 消息 MUST 被丢弃；本课不实现流式输出。
- 检索侧沿用并强化班级隔离：班级标识仅取自登录会话，查询串、请求头或 JSON 正文中的 `class_id` 一律丢弃；`keyword` 与 `vector` 两条路径都 MUST 按会话班级过滤，回表查询时再核对。跨班级检索对外表现为 HTTP 200 与空命中（或「资料中未找到相关内容」），不以 403/404 暗示资料归属。
- 失败与降级：空查询返回 400；Qdrant 不可用时 `keyword` 仍可返回结果，`vector` 与 `hybrid` 返回 503，不编造相似度分数。
- Compose 增加 Qdrant 服务与独立持久化卷；嵌入网关与对话网关仅由服务端调用，密钥不下发浏览器；不引入 LangChain/LlamaIndex 等编排框架，由 Go 自行完成切分、嵌入与检索。
- 本轮只生成 OpenSpec 文档（proposal/design/specs/tasks）；实现与 verify 任务保持未勾选，不生成业务代码或启动 Compose，也不改动第3课已归档的行为合同。

## Capabilities

### New Capabilities

- `knowledge-retrieval`: 本班范围内的正文切分与向量嵌入入库、keyword/vector/hybrid 三种检索、可回溯命中与引用标注、检索侧班级隔离，以及依赖（Qdrant、嵌入/对话网关）故障时的失败与降级行为。

### Modified Capabilities

无。材料上传、认证、会话与班级隔离的行为合同不变；本变更在其之上追加检索能力，且嵌入失败不回滚材料记录，故 `class-material-access` 的需求无需修改。

## Impact

新增 Qdrant 依赖、嵌入网关与对话网关的调用（仅服务端）、`knowledge_chunks` 表与 Qdrant 集合 `campusclaw_chunks`、检索与问答 API、前端检索页与引用展示，以及 Compose 的 Qdrant 服务与卷。复用现有认证/会话/班级上下文、材料模块与 MySQL。本轮无业务代码、数据库迁移或运行环境变更。

## Non-goals

不做流式输出与多轮对话编排（第5课）、交叉编码器重排序、Agent 工具调用式知识库、作业流程、注册找回、SSO；不引入 LangChain/LlamaIndex 等编排框架或 Dify 一类可视化知识库产品；不做生产高可用、跨班检索、按班级拆分 Qdrant 集合、分数归一化加权求和，也不将 Qdrant 端口映射到宿主机。已入库材料不会自动重新切分，切换策略须显式重建索引；重建失败不自动重试。
